## Chi tiết thiết kế và điểm lưu ý cho Claude khi nghiệm thu

1. **Giữ cô lập `.env` khi chạy pytest (`app/config/settings.py`):**
   `tests/conftest.py` đặt `PYTHON_DOTENV_DISABLED=1` nhưng `get_secret()` và `load_env_file()` trước đó vẫn truyền `dotenv_path=_ROOT / ".env"` vào `load_dotenv()`. Đã cập nhật để khi `PYTHON_DOTENV_DISABLED == "1"`, `load_env_file()` bỏ qua đọc `.env` và `get_secret()` gọi `load_dotenv(stream=io.StringIO(""), override=False)`, giúp giữ nguyên hành vi test `test_secrets_never_read_real_dotenv` trong khi tránh nạp `DATABASE_URL` từ `.env` làm nhiễu các test đặt tình huống thiếu tệp SQLite.

2. **Hai test hiện có ngoài phạm vi T75 sẽ cần cập nhật (không tự ý sửa theo quy tắc phạm vi):**
   - `tests/db/test_mapping.py::test_mapping_matches_schema_and_rls`: đang kiểm `set(blocks) == set(TABLES)`. Chín bảng bản sao chỉ mục ở `db/schema.sql` cố ý không thêm vào `app/db/mapping.py::TABLES` để không ảnh hưởng luồng `prepare_kb`/`expected_counts`/`load kb`/`verify` hiện tại.
   - `tests/db/test_schema_rds_compat.py::test_schema_revokes_supabase_roles_only_conditionally`: đang khẳng định `len(do_blocks) == 2`, nay `db/schema.sql` có 3 khối `DO $$ ... END $$;` (khối thứ ba thu hồi quyền `anon`/`authenticated` cho 9 bảng chỉ mục).

3. **Quan sát về `app/api/service.py` (nằm ngoài phạm vi T75):**
   - Luồng hỏi đáp (`/api/cases/{id}/ask`, `/api/ask`) qua `CaseService._build_default_asker` khi dùng đường dẫn mặc định gọi thẳng `container.case_asker`, do đó đọc kho đoạn từ `tri_thuc.doan_trich` khi thiếu `chunks.jsonl`.
   - `CaseService._build_default_ai_runner` (`AiReviewer`) và `CaseService.mode()` (`/api/health` → `che_do.truy_xuat`) vẫn kiểm tra trực tiếp `self._corpus_path.is_file()`.

4. **Ngưỡng `statement_timeout` trên `app/db/read_pool.py` (ngoài phạm vi T75):**
   `read_pool.connection()` đặt `SET LOCAL statement_timeout = 8000` (8 giây). Khi chạy thật trên RDS đọc lần đầu ~291.876 dòng của `tri_thuc.ddinter_cap`, cần kiểm tra xem có bị cắt timeout nếu đường truyền mạng chậm hay không.

## Lệnh nghiệm thu cần Claude chạy

```powershell
uv run ruff check .
uv run ruff format --check
uv run pytest -q -p no:cacheprovider
```

Sau khi cập nhật hai test schema nêu trên (nếu cần) và áp dụng `db/schema.sql` lên RDS:

```powershell
python -m app.db.cli load chi-muc --dry-run
python -m app.db.cli load chi-muc
python -m app.db.cli verify chi-muc
```
