## 3. Lệnh nghiệm thu (chờ Claude chạy)

```powershell
uv run ruff format app/rules/allergy.py app/rules/allergy_config.py app/rules/drug_disease.py app/rules/hepatic.py app/rules/max_dose.py app/rules/required_fields.py app/rules/toxicity.py tests/rules/test_allergy_resolver.py tests/rules/test_allergy_runtime.py tests/rules/test_lab_threshold.py tests/rules/test_renal_dose_d4.py
uv run ruff check .
uv run pytest -q -p no:cacheprovider
```
